# 🚑 Smart Ambulance System Dashboard

## 📌 Overview

The Smart Ambulance System Dashboard is a real-time web-based application designed to assist emergency responders in quickly identifying the nearest hospitals, checking bed availability, and navigating efficiently during critical situations. The system integrates location-based services with live hospital data to improve decision-making and reduce response time.

---

## 🚀 Features

* 🔍 **Location-Based Hospital Search**
  Enter a location or use GPS to find nearby hospitals instantly.

* 📍 **Distance Calculation**
  Displays the distance between the user and each hospital for quick comparison.

* 🛏️ **Real-Time Bed Availability (Firebase Integration)**
  Fetches live data such as available beds, ICU capacity, and emergency status from a real-time database.

* 🚨 **Emergency Mode**
  Highlights priority hospitals and enables faster selection during urgent situations.

* 🚗 **Navigation Support**
  Provides direct navigation links to selected hospitals using maps.

* 🗺️ **Interactive Map (Leaflet.js)**
  Visual representation of hospitals and routes with ambulance simulation.

* 🎛️ **Admin Panel**
  Allows updating hospital data (beds, ICU, emergency status) dynamically.

* 🎨 **Modern UI/UX**
  Clean, centered dashboard with gradient background, glassmorphism cards, and intuitive controls.

---

## 🧠 Problem Statement

In emergency situations, delays often occur due to lack of real-time hospital information and inefficient routing. This system addresses the gap by providing up-to-date hospital availability and optimized navigation for ambulance drivers.

---

## 💡 Solution

This dashboard combines:

* Geolocation services
* Real-time database (Firebase)
* Interactive mapping

to create a unified platform that enables fast, informed decisions in critical scenarios.

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Maps:** Leaflet.js + OpenStreetMap
* **Backend / Database:** Firebase Realtime Database
* **APIs Used:**

  * Nominatim (Geocoding)
  * Overpass API (Hospital Data)

---

## 🔄 How It Works

1. User enters a location or enables GPS
2. System fetches nearby hospitals using map APIs
3. Hospital data is displayed with distance
4. On selection, real-time data (beds, ICU, emergency) is fetched from Firebase
5. Navigation link guides ambulance to the hospital
